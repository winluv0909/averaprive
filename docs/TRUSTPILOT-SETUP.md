# Trustpilot setup

1. Claim the Avera Privé business profile using the official company email and production domain.
2. Complete Trustpilot's domain verification.
3. Copy the exact public business-profile URL into `NEXT_PUBLIC_TRUSTPILOT_PROFILE_URL` in Vercel.
4. If an official TrustBox is approved for the account, use the widget code generated inside Trustpilot Business. Do not recreate stars or scores manually.
5. Label the link as feedback about **Avera Privé as a platform**. It must remain separate from agency verification, agency reviews, objective rankings, and paid placements.
6. Remove any generic `trustpilot.com` placeholder link before launch if the official profile is not yet live.

Never import or display a Trustpilot rating without checking its current widget terms and attribution requirements.
